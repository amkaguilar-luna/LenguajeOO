# Herencia en Programación Orientada a Objetos (POO)

## 📖 Descripción

La herencia es uno de los principios fundamentales de la Programación Orientada a Objetos (POO). Permite crear nuevas clases a partir de clases existentes, reutilizando atributos y métodos para evitar la duplicación de código.

Gracias a la herencia, una clase hija (subclase) puede heredar las características de una clase padre (superclase) y además agregar o modificar funcionalidades según sea necesario.
